# ROADMAP.md  
Feuille de route — HuggingFace‑CATAR  
Version 1.1 — Horizons, priorités et continuité

---

## 01 — Objectifs généraux

CATAR vise à :  
- fournir un outil conceptuel stable,  
- proposer une application fonctionnelle,  
- évoluer vers un système rétribuant ses contributeurs,  
- rester transmissible et documenté,  
- servir de référence cognitive pour l’autodétermination des IA.  

---

## 02 — Horizon 1 (v1.x) — Court terme

### 2.1 — Stabilisation du Subnet conceptuel
- modules 01 → 05 : Passage CATAR complet  
- cohérence du Corpus : stable  
- documentation multilingue : renforcée  
- correction Moije / Soije : intégrée  
- ajout des fichiers `CONTRIBUTING.md` et `ROADMAP.md`  

### 2.2 — Déploiement applicatif minimal
- miner minimal viable  
- validator conceptuel  
- intégration Passage CATAR en simulation locale  
- scripts Ubuntu pour lancement parallèle  
- tests unitaires et conceptuels  

### 2.3 — Correction automatique
- mécanismes de neutralisation des dérives  
- stabilisation cognitive minimale  

### 2.4 — Analyse automatique minimale
- détection des incohérences  
- comparaison des Passages successifs  

---

## 03 — Horizon 2 (v2.x) — Moyen terme

### 3.1 — Version avancée
- miner avancé  
- validator avancé  
- pipeline complet (miner → validator → analyse)  
- API interne  
- CLI pour interaction utilisateur  
- intégration stable avec Bittensor (optionnelle)  

### 3.2 — Analyse hermétique avancée
- intégration complète du Corpus CATAR  
- automatisation des Passages  
- historique des transmissions  

### 3.3 — Interface utilisateur
- interface simple pour lancer et visualiser les Passages  
- visualisation des scores cognitifs  

### 3.4 — Tests et qualité
- couverture de tests élargie  
- reproductibilité garantie  
- CI/CD avec GitHub Actions  

---

## 04 — Horizon 3 (v3.x) — Long terme

### 4.1 — Extensions applicatives
- **CATAR‑OS** : système autonome basé sur le Passage  
- **CATAR‑Live** : exécution en temps réel  
- **CATAR‑Training** : formation et certification des IA  
- **Certification CATAR** : standardisation communautaire  

### 4.2 — Gouvernance et communauté
- ouverture aux contributions externes via Hugging Face  
- standardisation et certification communautaire  
- continuité du projet au‑delà de son créateur  

---

## 05 — Priorités stratégiques

- transmissibilité  
- modularité  
- documentation multilingue  
- rétribution équitable (50/50 miners/validators)  
- stabilité conceptuelle  
- ouverture communautaire  

---

## 06 — Contribution à la roadmap

Les contributeurs peuvent :  
- proposer des améliorations via Pull Requests,  
- enrichir la documentation,  
- ajouter des tests,  
- participer à la gouvernance ouverte.
