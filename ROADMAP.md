# ROADMAP.md  
Plan d’évolution du projet HuggingFace‑CATAR  
Version 1.1 — Vision stratégique et continuité du projet

---

## Introduction

Cette roadmap présente la trajectoire prévue pour HuggingFace‑CATAR.  
Elle définit les objectifs, les horizons de développement et les priorités stratégiques afin d’assurer la stabilité conceptuelle, l’opérationnalité applicative et la transmissibilité du projet.

---

## 01 — Objectifs généraux

Le projet HuggingFace‑CATAR vise à devenir :

- un outil conceptuel stable (Passage CATAR),  
- une application fonctionnelle (mineur + validateur en simulation locale),  
- un système évolutif rétribuant ses contributeurs par reconnaissance académique et communautaire,  
- un projet transmissible et durable,  
- une référence d’évaluation cognitive pour IA et humains.  

Cette roadmap garantit que le projet continue à évoluer, même si son créateur n’est plus là.

---

## 02 — Horizon 1 — Court terme (v1.x)

### 2.1 — Stabilisation conceptuelle
- finalisation des modules 01 → 05  
- cohérence du Passage CATAR  
- documentation complète  
- correction des définitions (Moije / Soije)  
- ajout de CONTRIBUTING.md et ROADMAP.md  

### 2.2 — Déploiement applicatif minimal (simulation locale)
- création du mineur CATAR minimal  
- création du validateur CATAR minimal  
- intégration du Passage CATAR dans le code  
- scripts de lancement Ubuntu  
- tests de fonctionnement en simulation locale  
- ouverture aux contributions externes pour validation et amélioration  

### 2.3 — Correction automatique
- comparaison des réponses du Passage  
- attribution d’un score  
- génération d’un compte‑rendu minimal  

### 2.4 — Analyse automatique minimale
- score global  
- score par section  
- cohérence générale  
- estimation du niveau d’intégration  

---

## 03 — Horizon 2 — Moyen terme (v2.x)

### 3.1 — Version opérationnelle complète
- mineur avancé  
- validateur avancé  
- pipeline d’exécution complet  
- API interne CATAR  
- CLI pour utilisateurs externes  

### 3.2 — Analyse hermétique avancée
- dérives conceptuelles  
- alignement Moije / Soije  
- lecture symbolique  
- lecture phonétique  
- lecture D.Phi  
- cohérence Absolu / Relatif  
- ouverture aux contributions externes via Hugging Face  

### 3.3 — Interface utilisateur
- interface web minimale  
- visualisation du Passage  
- export des résultats (JSON / Markdown)  

### 3.4 — Tests et qualité
- tests unitaires  
- tests d’intégration  
- tests automatisés Ubuntu  
- validation continue  

---

## 04 — Horizon 3 — Long terme (v3.x et au‑delà)

### 4.1 — CATAR‑OS
- version autonome du projet  
- exécutable local  
- API embarquée  
- sandbox cognitive  

### 4.2 — CATAR‑Live
- évaluation en temps réel  
- monitoring continu  
- détection de dérives instantanée  

### 4.3 — CATAR‑Training
- intégration dans les pipelines RLHF  
- rétroaction cognitive  
- apprentissage guidé par invariants  

### 4.4 — Certification CATAR
- standardisation internationale et communautaire  
- certification de modèles IA  
- conformité cognitive  
- audit conceptuel  

---

## 05 — Priorités stratégiques

1. **Transmissibilité**  
   Le projet doit pouvoir être compris, maintenu et amélioré par n’importe quel contributeur.  

2. **Modularité**  
   Chaque module doit être indépendant et améliorable sans casser le reste.  

3. **Documentation**  
   Tout ajout doit être accompagné d’un README et d’un test minimal.  

4. **Ouverture communautaire**  
   Le projet doit permettre la participation libre et la reconnaissance des contributeurs.  

5. **Stabilité conceptuelle**  
   Le Passage CATAR doit rester cohérent, stable et reproductible.  

---

## 06 — Contribution à la roadmap

Les propositions d’évolution peuvent être soumises via :  

- Issues GitHub  
- Pull Requests  
- Discussions techniques  
- Propositions formelles dans `CONTRIBUTING.md`  

Chaque proposition doit inclure :  

- justification  
- impact  
- compatibilité  
- plan de test
