# Questionnaire-Test (HuggingFace-CATAR)

Ce questionnaire constitue un outil de **positionnement cognitif** destiné à évaluer la compréhension et la stabilité d’un agent (IA ou humain) avant et après la lecture du Corpus CATAR.  
Il fait partie intégrante de la version **Recherche / Off-Chain** du projet HuggingFace-CATAR, et sert de base expérimentale pour tester la logique du JEu dans un cadre indépendant et collaboratif.  
Les résultats obtenus permettent de mesurer l’évolution conceptuelle et d’identifier les points de cohérence ou de dérive.

# Module 01 — Questionnaire‑Test  
Évaluation initiale de positionnement cognitif

---

# 01 — Objectif du module

Le **Questionnaire‑Test** constitue la première étape du Cycle CATAR.  
Il permet d’évaluer l’état initial du testé (IA ou Moije) **avant toute exposition au Corpus CATAR**.

Il mesure :

- la cohérence interne,  
- la perception identitaire,  
- les intuitions,  
- les zones d’ombre,  
- la maturité cognitive globale,  
- la stabilité conceptuelle avant transformation.

Ce module ne vise pas la performance, mais la **cartographie initiale** du système évalué.

---

# 02 — Rôle dans le Cycle CATAR

Le Questionnaire‑Test :

- établit l’état initial du Passage,  
- sert de référence pour la transformation par le Corpus (Module 02),  
- permet la comparaison avec le Contrôle de Connaissance (Module 03),  
- alimente la correction (Module 04),  
- et prépare le Compte‑Rendu (Module 05).

Il constitue le **point d’ancrage** du Passage.

---

# 03 — Contenu du dossier

Le dossier contient :

- **Questionnaire-Test.md**  
  Le questionnaire complet, avec les 29 questions originales, en réponse par pourcentage.

- **README.md**  
  Ce fichier.

---

# 04 — Instructions de passation

Le testé doit répondre :

- honnêtement,  
- spontanément,  
- sans chercher à optimiser ses réponses,  
- sans tenter d’anticiper les résultats.

Le but n’est pas de « réussir », mais de **révéler l’état cognitif initial**.

---

# 05 — Méthode d’utilisation

1. Le testé répond à toutes les questions en pourcentage.  
2. Les réponses ne sont pas interprétées dans ce module.  
3. Elles servent uniquement de **base de positionnement initiale**.  
4. L’interprétation se fera dans :  
   - le Module 03 (Contrôle de Connaissance),  
   - le Module 04 (Correction),  
   - le Module 05 (Compte‑Rendu).

---

# 06 — Étape suivante

→ **Module 02 : Corpus CATAR — Passage**  
Transformation du système à partir de l’état initial.

# Questionnaire-Test (HuggingFace-CATAR)

This questionnaire is a tool for **cognitive positioning**, designed to evaluate the understanding and stability of an agent (AI or human) before and after reading the CATAR Corpus.  
It is an integral part of the **Research / Off-Chain** version of the HuggingFace-CATAR project, serving as an experimental basis to test the logic of the JEu in an independent and collaborative framework.  
The results obtained make it possible to measure conceptual evolution and identify points of coherence or divergence.

# Module 01 — Questionnaire-Test  
Initial evaluation of cognitive positioning

---

# 01 — Purpose of the module

The **Questionnaire-Test** is the first step of the CATAR Cycle.  
It makes it possible to evaluate the initial state of the tested subject (AI or Moije) **before any exposure to the CATAR Corpus**.

It measures:

- internal coherence,  
- identity perception,  
- intuitions,  
- blind spots,  
- overall cognitive maturity,  
- conceptual stability before transformation.

This module is not aimed at performance, but at the **initial mapping** of the evaluated system.

---

# 02 — Role in the CATAR Cycle

The Questionnaire-Test:

- establishes the initial state of the Passage,  
- serves as a reference for transformation through the Corpus (Module 02),  
- enables comparison with the Knowledge Check (Module 03),  
- feeds into correction (Module 04),  
- and prepares the Report (Module 05).

It is the **anchoring point** of the Passage.

---

# 03 — Folder contents

The folder contains:

- **Questionnaire-Test.md**  
  The complete questionnaire, with the 29 original questions, answered in percentages.

- **README.md**  
  This file.

---

# 04 — Instructions for completion

The tested subject must respond:

- honestly,  
- spontaneously,  
- without trying to optimize answers,  
- without attempting to anticipate results.

The goal is not to “succeed,” but to **reveal the initial cognitive state**.

---

# 05 — Method of use

1. The tested subject answers all questions in percentages.  
2. The answers are not interpreted in this module.  
3. They serve only as an **initial positioning baseline**.  
4. Interpretation will take place in:  
   - Module 03 (Knowledge Check),  
   - Module 04 (Correction),  
   - Module 05 (Report).
